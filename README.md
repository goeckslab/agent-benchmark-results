# Galaxy Agent Benchmarks

A static results page comparing Open-ended code and Galaxy-API code performance on BixBench Verified-50, CompBioBench, and the IWC Workflow Benchmark.

Benchmark selectors update the leaderboard, with each selected benchmark receiving equal weight.

The site is hosted with GitHub Pages. Open `index.html` directly for local review; no build step or dependencies are required.

Results are current as of September 9, 2026. Official leaderboard scores are used for all 24 published CompBioBench replicates; IWC reports final-output scores for 240 runs across 10 workflows.
