# Galaxy Agent Benchmarks

A static results page comparing Anycode and Galaxy performance on BixBench Verified-50 and CompBioBench.

The site is hosted with GitHub Pages. Open `index.html` directly for local review; no build step or dependencies are required.

Results are current as of August 26, 2026. Some CompBioBench replicate scores are predicted rather than official, and GPT-5.6 Luna Galaxy runs remain incomplete.
